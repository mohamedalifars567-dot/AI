# منصة أسعار الصرف

تطبيق ويب عربي لعرض أسعار العملات وتحويل مبلغ بين عملتين باستخدام [Frankfurter API](https://frankfurter.dev/).

## ملفات المشروع

- `index .html`: بنية الصفحة وعناصر واجهة المستخدم. يستورد Tailwind CSS وFont Awesome من CDN، ثم يحمّل ملف JavaScript.
- `api.js`: مسؤول عن التواصل مع Frankfurter API فقط، ويقدم وظائف لجلب العملات والأسعار والتحويل.
- `script.js`: منطق واجهة المستخدم: تعبئة القوائم، عرض نتيجة التحويل وجدول الأسعار، والبحث والتبديل بين العملات. لا ينفذ طلبات `fetch` مباشرة.
- `README.md`: وصف المشروع وطريقة تشغيله.

لا يوجد ملف CSS مستقل لأن تصميم الصفحة مكتوب باستخدام أصناف Tailwind مباشرة في HTML.

## كيف يعمل التطبيق؟

1. يحمّل HTML ملف `api.js` أولًا، ثم ملف `script.js`.
2. عند تحميل الصفحة، يستدعي `script.js` وظائف `api.js` لجلب قائمة العملات ثم يملأ القوائم المنسدلة.
3. يبدأ التحويل بالقيم الافتراضية، ويجلب أسعار الجدول نسبةً إلى عملة الأساس المختارة.
4. عند تغيير المبلغ أو إحدى عملتي التحويل، يُحدّث التطبيق نتيجة التحويل وسعر الوحدة.
5. يمكن تبديل العملتين، أو تغيير عملة الأساس للجدول، أو تصفية الجدول بالرمز أو الاسم.
6. تظهر أخطاء الاتصال بقائمة التنبيه العامة، أو بجانب نتيجة التحويل في حالة فشل طلب التحويل.

## التشغيل

شغّل الصفحة عبر خادم HTTP محلي، مثل إضافة Live Server في VS Code، ثم افتح `index .html` في متصفح حديث. يلزم الاتصال بالإنترنت لتحميل مكتبات CDN وطلب بيانات Frankfurter API.
